# ☕ Coffee Heaven – Brand Website

## 📌 Project Overview

**Coffee Heaven** is a simple and responsive coffee brand website developed using HTML and CSS. The website presents a coffee-themed design with a navigation sidebar, an attractive background image, a short brand introduction, and a collection of coffee product images.

This project was created as part of **Internship Task 1** to practice web design and responsive layouts.

## 🎯 Objectives

- Build a simple and attractive brand website.
- Practice HTML structure and CSS styling.
- Create a sidebar navigation menu.
- Add background images and product images.
- Implement responsive design for smaller screens.

## 🛠️ Technologies Used

- **HTML5** – For structuring the webpage.
- **CSS3** – For styling, layouts, hover effects, and responsiveness.
- **Google Fonts** – For custom typography using the Pacifico font.

## ✨ Features

- Coffee-themed website design.
- Sidebar containing the brand name, coffee image, and navigation links.
- Hero section with a coffee background image and introductory text.
- Hot Products section displaying three coffee images.
- Hover effect on navigation links.
- Responsive layout for mobile devices using CSS media queries.
- Flexbox layout for arranging page sections and product images.

## 📱 Responsive Design

The website uses CSS media queries to adjust its layout for screens with a maximum width of 768px.

On smaller screens:
- The sidebar moves above the main content.
- The sidebar height adjusts automatically.
- The coffee image in the sidebar becomes smaller.
- Product images are arranged vertically.
- Product images expand to fit the available screen width.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Make sure `internship task 1.html` and `internship task 1.css` are in the correct locations.
3. Open the project folder in Visual Studio Code.
4. Open `internship task 1.html` in your browser, or use the Live Server extension.
5. Resize the browser window to test the responsive layout.
